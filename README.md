# yep-21

Marketing website foundation for the yep-21 freelance marketplace.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Implemented routes

- `/` Home
- `/about` About
- `/blog` Blog list
- `/blog/:id` Blog detail

Newsletter subscription flow is implemented with a mock API layer matching `POST /newsletter/subscribe` semantics.
